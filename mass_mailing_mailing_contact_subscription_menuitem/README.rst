===================================================
Mass Mailing: Mailing Contact Subscription Menuitem
===================================================

This module adds a "Mailing Subscriptions" menu item to Email
Marketing, listing every mailing list subscription in its own view
instead of only through a contact's subscriptions list on its form.

This is useful when a contact cannot be opted out directly from that
list, for example because the mailing list is fully synchronized (as
with ``mass_mailing_list_dynamic``) and editing it manually is blocked.

Configuration
=============
\-

Usage
=====

#. Go to **Email Marketing > Configuration > Mailing Subscriptions**.
