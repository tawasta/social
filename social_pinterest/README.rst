===============================
Social Pinterest
===============================

* Adds Pinterst social media service to Odoo
* Works similarly to the existing social media platforms in Odoo
* Adds platforms to the company form, where the link can be modified
* Includes the needed icons to be used in printing 

Configuration
=============
* Settings -> Companies -> Company -> Social media -> Pinterest
