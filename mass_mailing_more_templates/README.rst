===========================================
Mass Mailing: More Templates
===========================================

* Adds company themed dynamic templates to mass mailing.
* Templates have company name and logo along with social media links, which
it gets from the env.company object.

Configuration
=============
* None needed

Usage
=====
* Adds new templates to mass mailing template selection dialog.
