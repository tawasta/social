===============================
Mail compose attachment preview
===============================

Attachments in the e-mail composer and in scheduled messages open in a new
browser tab for preview instead of being downloaded.

Configuration
=============
\-

Usage
=====
Send an e-mail from any record (e.g. a sale or purchase order) and click an
attachment name in the composer.
